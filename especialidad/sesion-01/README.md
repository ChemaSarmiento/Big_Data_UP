# Sesión 01 — Big Data para decisiones de negocio

> Programa completo (evaluación, notas de facilitación): [`PROGRAMA.md`](../PROGRAMA.md)

## Índice
1. Las 5 V's, con ejemplos de industria (banca, retail, salud)
2. Cuándo sí se necesita Big Data y cuándo un Excel/base tradicional basta
3. Panorama del ecosistema (storage, cómputo, streaming, orquestación) a nivel de mapa

## Actividad
Análisis de 2-3 casos reales: el grupo decide si el caso justificaba una inversión en Big Data o fue sobre-ingeniería.

## Entregable
Ficha de 1 página con un caso propio de su industria (¿aplica Big Data o no, y por qué?).

## Ejemplo / material de apoyo
Caso de discusión: "Un banco quiere saber cuántas transacciones tuvo cada sucursal el mes pasado" (no justifica Big Data, es una query de SQL tradicional) vs. "un banco quiere detectar fraude en el momento en que ocurre la transacción, sobre millones de transacciones diarias" (sí lo justifica). Usar `recursos/etl-cripto/FLUJO.md` como ejemplo visual de a qué se parece un pipeline real, sin entrar al código.
