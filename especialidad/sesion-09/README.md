# Sesión 09 — Presentación de propuestas

> Programa completo (evaluación, notas de facilitación): [`PROGRAMA.md`](../PROGRAMA.md)

## Índice
1. Presentación de la propuesta de arquitectura + caso de negocio (10 min c/u)
2. Retroalimentación cruzada
3. Siguientes pasos (para quien quiera profundizar, mención del track de Maestría)

## Actividad principal
Cada participante o equipo presenta una propuesta de arquitectura con caso de negocio para un problema real de su área: qué se necesita, por qué, costo aproximado y riesgos.

## Entregable
Propuesta final: (1) problema de negocio y por qué justifica Big Data, (2) esquema de arquitectura a nivel conceptual, (3) estimación de costo/beneficio, (4) riesgos y consideraciones de gobernanza. No se evalúa código productivo.

## Ejemplo / material de apoyo
Usar la tabla de criterios de evaluación de `PROGRAMA.md` (Sección 5) como rúbrica explícita frente al grupo antes de que empiecen las presentaciones.
