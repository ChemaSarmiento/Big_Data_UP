# S5 · Una canasta incompleta parece una ganga

27 slides /180 minutos. [Deck](../../../presentaciones-v2/especialidad-05/index.html) · [Guía](../../../presentaciones-v2/especialidad-05/laboratorio.html).

Gran idea: Una comparación justa conserva el mismo contrato, población y denominador.

Syllabus: modelo de negocio y capa Gold; catálogo, joins, selección temporal, KPIs y consumo BI. SQL guiado, sin programación de ventanas desde cero. Gold se implementa como tablas con actualización explícita; no se promete soporte de cualquier consulta como vista materializada. Cada proyecto conserva dataset distinto.
