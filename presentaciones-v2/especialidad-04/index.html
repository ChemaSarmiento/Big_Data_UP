Un CTE le pone nombre a un paso para leer el resto

21_silver_autores.sql · formato ajustado
CREATE OR REPLACE TABLE tweets_silver.autores AS
WITH ordenados AS (
  SELECT usuario, usuario_verificado, seguidores,
    NULLIF(TRIM(ubicacion_usuario), '')
      AS ubicacion,
    ROW_NUMBER() OVER (
      PARTITION BY usuario
      ORDER BY fecha_hora DESC) AS orden,
    COUNT(*) OVER (PARTITION BY usuario)
      AS tweets_en_archivo
  FROM tweets_silver.tweets
)
SELECT usuario, usuario_verificado,
  seguidores, ubicacion, tweets_en_archivo
FROM ordenados
WHERE orden = 1;

Idioma sin determinar y ubicación vacía: dato ausente no es cero
