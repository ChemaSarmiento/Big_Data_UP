ESPECIALIDAD / SESIÓN 1 · PASO PILOTO · 10–15 MINUTOS

Identifica el proyecto
y configura sus avisos.

Al terminar tendrás el ID del proyecto, el alcance del presupuesto y la persona que recibe los avisos.

Esta guía no ejecuta acciones en tu cuenta. El script solo lee configuración. Las instrucciones están contrastadas con documentación oficial; aún no se han ensayado en la cuenta GCP de clase. Interfaz consultada: 5 de noviembre de 2026.

Antes de empezar

  • Cuenta Google con acceso a un proyecto de laboratorio y facturación vinculada. Comprueba por separado tu elegibilidad y crédito restante; este paso no activa crédito.
  • Permisos para consultar el proyecto y crear/ver presupuestos en el alcance elegido. Si no los tienes, pide al responsable docente completar el paso y usa su evidencia; no cambies a una cuenta de pago para seguir la clase.
  • Un importe operativo acordado y el destinatario responsable. Para este ejemplo usaremos US$60 como presupuesto total de práctica, sin presentarlo como cotización ni límite garantizado.

1. Confirma el ID del proyecto

  1. Abre Google Cloud Console y elige el proyecto en el selector superior. Anota su ID, no solo su nombre visible.
  2. Abre Cloud Shell desde el icono de terminal de la consola. Cuando esté listo, pega:
gcloud config get project

Descargar el comando como .sh. Es una consulta de solo lectura; también puedes pegarla sin descargar nada.

Debes observar: un ID que coincida con el proyecto de laboratorio seleccionado. No compartas credenciales ni tokens en tu evidencia.

Si aparece (unset) o un proyecto distinto: verifica el ID en el selector. Para establecer el proyecto de la CLI, reemplaza ID_DE_TU_PROYECTO por ese ID y ejecuta:

gcloud config set project ID_DE_TU_PROYECTO
gcloud config get project

El primer comando cambia la configuración de la CLI, no crea un proyecto. El segundo comprueba el resultado. Si recibes un error de acceso, confirma la cuenta activa con el docente; no pruebes con proyectos ajenos.

2. Crea un presupuesto de alertas

  1. En la consola, abre Facturación y selecciona la cuenta vinculada al proyecto. Entra a Presupuestos y alertas → Crear presupuesto. Si la etiqueta cambió, consulta el procedimiento oficial.
  2. Nombre sugerido: profeco-practica. Restringe el alcance al proyecto de laboratorio; comprueba que no incluya proyectos ajenos. Elige todos los servicios del proyecto para no omitir una categoría de consumo.
  3. Define el periodo del curso si está disponible como rango personalizado, o el periodo acordado con el docente. Si eliges mensual, recuerda que el importe vuelve a aplicar cada mes.
  4. Revisa la moneda de la cuenta. Introduce 60 únicamente si el presupuesto está denominado en USD; en otra moneda, acuerda el equivalente antes de guardar.
  5. Para observar consumo bruto del ejercicio, revisa el tratamiento de créditos promocionales: si se descuentan, el costo mostrado puede quedar en cero mientras consumes el crédito. Documenta si los incluyes o excluyes.
  6. Configura umbrales de 25%, 50%, 75% y 100% de gasto real. Para un presupuesto de US$60 equivalen a US$15, 30, 45 y 60. Comprueba qué administradores o destinatarios recibirán el aviso y guarda.

Debes observar: el presupuesto guardado con el alcance, periodo, moneda, tratamiento de créditos y umbrales elegidos. No se espera recibir un correo instantáneo: la notificación depende del consumo y la actualización de facturación.

Si no encuentras la cuenta o no puedes guardar: verifica proyecto y permisos con el responsable. En una cuenta compartida, consulta el presupuesto ya configurado; evita crear duplicados para cada intento.

Un presupuesto de alertas no detiene el gasto. Acuerda quién revisa el aviso y qué recursos puede detener. Los costos pueden actualizarse con demora. Este piloto no configura apagados automáticos.

3. Guarda tu evidencia

  • ID de proyecto y fecha de comprobación.
  • Nombre del presupuesto, alcance y periodo.
  • Importe, moneda, umbrales y tratamiento de créditos.
  • Destinatario o rol que recibirá los avisos y acción que seguirá al recibirlos.

Conserva una captura sin información sensible. No la publiques en el sitio del curso. Puedes empezar tu ficha de decisión en la última pantalla del piloto.

Al terminar

Este ejercicio no ha creado cómputo ni tablas. El presupuesto permanece activo para seguimiento. Revisa por separado si tenías máquinas, discos u otros recursos ya activos: cerrar Cloud Shell o esta página no detiene esos recursos.
