08 / LABORATORIO GUIADO 10–15 MIN · CUENTA GCP PREPARADA

Antes de consultar,
identifica quién paga y quién recibe avisos.

  1. Confirma el proyecto.

    En Cloud Shell, consulta el ID activo. Debe coincidir con el selector de la consola.

  2. Crea un presupuesto de alertas.

    Facturación → Presupuestos y alertas. Selecciona el proyecto y revisa destinatarios.

  3. Guarda la comprobación.

    Registra proyecto, alcance, importe y destinatario. Un aviso no detiene el gasto.
