ESPECIALIDAD / S3 · 180 MINUTOS

Bronze conserva la evidencia y permite consultarla

Material local para revisión. Datos y resultados del fixture son ilustrativos: no provienen de filas de PROFECO ni demuestran escala. Los pasos cloud requieren cuenta, permisos, región y ensayo previo del docente. No se han ejecutado en GCP desde este sitio.

Preparación, herramientas y ruta exacta

Ruta principal: en Cloud Storage subir precios-ilustrativos.csv; crear datasets de laboratorio en ubicación compatible; en BigQuery abrir 02_bronze_externa.sql y sustituir uri por la URI exacta del objeto; ejecutar después 03_explorar.sql. Ruta de recuperación: 01_fixture_bronze.sql recrea la entrada como tabla nativa sin descargar nada. Esta recuperación NO demuestra una tabla externa ni escala real. Ambos scripts usan solo tablas curso_*. Para la fuente grande, el docente debe perfilar el esquema y preparar GCS/permisos/consulta acotada antes de clase; no se reutilizan las ocho columnas del fixture como contrato de all_data.csv.

Paso 1 · 5 min

Acción: En Cloud Storage → Buckets, abrir el bucket de S1. Crear prefijo bronze y subir precios-ilustrativos.csv sin editarlo. Descargar manifiesto-fixture.json.

Comprobación y recuperación: En detalles del objeto, copiar URI gs://, tamaño y ubicación. Si falla subida, revisar identidad y permiso docente; no publicar el bucket.

Paso 2 · 8 min

Acción: Abrir BigQuery Studio → editor SQL. Confirmar proyecto de laboratorio. Crear curso_bronze con ubicación compatible (script propone us-central1).

Comprobación y recuperación: Ver dataset y ubicación en Explorador. IF NOT EXISTS no cambia ubicación existente. Silver y Gold se crearán en sus sesiones.

Paso 3 · 12 min

Acción: Abrir 02_bronze_externa.sql. Reemplazar solo la URI por la del CSV subido; leer DDL y ejecutar hasta la consulta de muestra.

Comprobación y recuperación: En curso_bronze, verificar observaciones_externas, esquema completo de ocho columnas y URI. Si hay parseo fallido, comprobar CSV, cabecera y orden de campos.

Paso 4 · 12 min

Acción: Consultar COUNT(*) de observaciones_externas; después ejecutar el CTAS de 02_bronze_externa.sql y las consultas de 03_explorar.sql.

Comprobación y recuperación: 16 filas de entrada (sin cabecera); 15 distintas en la copia nativa. El CTAS crea observaciones_raw sin limpiar. Si difiere, contrastar archivo/manifiesto, no eliminar registros a mano.

Paso 5 · 10 min

Acción: En historial/detalles del job, guardar ID, bytes procesados/facturados, caché, tiempo y filas devueltas. Consultar fuente grande solo si docente preparó esquema, acceso y límite de costo.

Comprobación y recuperación: Estimar antes y revisar máximo de bytes facturados donde aplique. Externas pueden no tener estimación completa: 0 no prueba costo nulo. Sin condiciones, marcar escala pendiente; no sustituir por métricas inventadas.

Paso 6 · 8 min

Acción: Guardar manifiesto con URI, versión, fecha de recepción, ubicación, esquema, permisos y SQL. Otro equipo reconstruye la lectura.

Comprobación y recuperación: Distinguir fixture/muestra/fuente completa. Conservar CSV y tablas para Silver; revisar retención y accesos. Fuente sin permiso validado queda pendiente, aunque sea descargable.

02_bronze_externa.sql · ver contenido completo
-- GoogleSQL. Subir precios-ilustrativos.csv al bucket del equipo ANTES de ejecutar.
-- Cambiar SOLO uri por el objeto real. Este esquema es del FIXTURE, no all_data.csv.
DECLARE uri STRING DEFAULT 'REEMPLAZAR_POR_URI_GS_DEL_CSV_ILUSTRATIVO';
ASSERT (STARTS_WITH(uri, 'gs://')) AS 'Reemplaza uri por el objeto del fixture subido a GCS';
CREATE SCHEMA IF NOT EXISTS curso_bronze OPTIONS(location='us-central1');
EXECUTE IMMEDIATE FORMAT("""
CREATE OR REPLACE EXTERNAL TABLE curso_bronze.observaciones_externas (
 id STRING, producto STRING, marca STRING, presentacion STRING,
 establecimiento STRING, fecha_texto STRING, precio_texto STRING, archivo_origen STRING
) OPTIONS (format='CSV', uris=[%T], skip_leading_rows=1)
""", uri);
-- Fuente y dataset deben tener ubicación compatible.
SELECT id, producto, establecimiento, fecha_texto, precio_texto
FROM curso_bronze.observaciones_externas ORDER BY id LIMIT 10;
-- Materializar copia de trabajo del fixture para S4/S5; conserva el CSV original.
CREATE OR REPLACE TABLE curso_bronze.observaciones_raw AS
SELECT * FROM curso_bronze.observaciones_externas;
SELECT COUNT(*) AS filas FROM curso_bronze.observaciones_raw; -- 16 en el fixture
