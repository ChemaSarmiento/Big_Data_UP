La frase suena lista. La evidencia todavía no

Las consultas SQL de esta guía se ejecutaron con datos reales y sus resultados se muestran tal cual. Vertex AI Studio no se ensayó desde esta guía: los nombres de menú pueden variar y el texto que genere un modelo cambia en cada ejecución. Las cifras de referencia pueden variar ligeramente en tus tablas.

Antes de empezar

  • Tus tablas Silver y Gold de las sesiones anteriores, en un proyecto con facturación activa: tweets_silver.tweets, tweets_silver.autores, tweets_gold.tema_dia, hashtags_dia, autores_alcance, aplicaciones_dia, actividad_hora y conversacion_dia (ubicación US).
  • Permiso para usar BigQuery y Vertex AI en tu proyecto.
  • Dos pestañas abiertas: BigQuery Studio y Vertex AI Studio.
  • Un editor de texto para armar tu prompt antes de pegarlo.

Preparación, herramientas y ruta exacta

BigQuery Studio → elige tu proyecto en el selector → Nueva consulta. Pega un bloque a la vez, mira el estimador de bytes antes de ejecutar y copia la celda de resultado que se indica. Después abre Vertex AI Studio desde la consola de Google Cloud (busca «Vertex AI Studio» en la barra de búsqueda). Los pasos 1, 2 y 5 son SQL; el paso 3 es redacción; el paso 4 es la herramienta de IA; el paso 6 es tu cierre.

Paso 1 · Recuperar cinco tweets con SQL · 10 min

Dónde: BigQuery Studio → Nueva consulta, con tu proyecto elegido.

Acción: Pega el bloque 1 y ejecútalo; antes, mira el estimador de bytes. Después ejecuta el bloque 2, que arma esos mismos cinco tweets como un solo texto numerado, y copia la celda «contexto». Prueba otra fecha o idioma y compara el estimador.

Costo estimado: ≈ 82 MB por bloque: el filtro por fecha y por idioma lee solo esa parte de tweets_silver.tweets (referencia del curso; tu editor mostrará el tuyo).

-- Paso 1 · Recuperar. Los 5 tweets en inglés con más likes que mencionan energía el 23 de marzo de 2022.
-- Filtra por fecha (partición) y por idioma (cluster) antes de ordenar: así lees una fracción de la tabla.
SELECT likes, url, SUBSTR(texto, 1, 230) AS texto
FROM tweets_silver.tweets
WHERE fecha = DATE '2022-03-23'
  AND idioma = 'en'
  AND REGEXP_CONTAINS(LOWER(texto), r'\b(oil|gas|fuel|petrol|energy)\b')
ORDER BY likes DESC
LIMIT 5;

-- Lo mismo, pero armado como UN solo texto numerado, listo para copiar en el prompt.
SELECT STRING_AGG(FORMAT('[%d] (%d likes) %s %s', n, likes, url, texto), '\n' ORDER BY n) AS contexto
FROM (
  SELECT ROW_NUMBER() OVER (ORDER BY likes DESC) AS n, likes, url,
         REPLACE(SUBSTR(texto, 1, 230), '\n', ' ') AS texto
  FROM tweets_silver.tweets
  WHERE fecha = DATE '2022-03-23'
    AND idioma = 'en'
    AND REGEXP_CONTAINS(LOWER(texto), r'\b(oil|gas|fuel|petrol|energy)\b')
  ORDER BY likes DESC
  LIMIT 5
);

Paso 2 · Armar un contexto con tablas Gold · 12 min

Dónde: BigQuery Studio → Nueva consulta.

Acción: Ejecuta el script completo. Devuelve una celda «contexto» con seis líneas numeradas [T1] a [T6], una por tabla Gold, con su nombre, filtro y base. Cópiala. Lee cada línea: ¿de qué tabla viene, qué cubre y contra qué base se mide?

Costo estimado: ≈ 38 KB procesados: las tablas Gold ya están resumidas.

-- Paso 2 · Armar un contexto con TABLAS Gold: una línea numerada por tabla, con su nombre, filtro y base.
-- Cada línea lleva su etiqueta [T1]…[T6] para que el modelo pueda citarla y tú puedas auditarla.
WITH t1 AS (
  SELECT 1 AS o, FORMAT('[T1] tweets_gold.tema_dia · 2022-03-23 · inglés · base %d tweets: %s',
         ANY_VALUE(tweets_dia),
         STRING_AGG(FORMAT('%s %d (%.3f %%)', tema, tweets_tema, pct_del_dia), '; ' ORDER BY pct_del_dia DESC)) AS linea
  FROM tweets_gold.tema_dia
  WHERE fecha = DATE '2022-03-23' AND grupo_idioma = 'en'
),
t2 AS (
  SELECT 2, FORMAT('[T2] tweets_gold.hashtags_dia · 2022-03-23 · cinco hashtags con más tweets: %s',
         STRING_AGG(FORMAT('#%s %d (%.3f %%)', hashtag, tweets, pct_del_dia), '; ' ORDER BY tweets DESC))
  FROM (SELECT hashtag, tweets, pct_del_dia FROM tweets_gold.hashtags_dia
        WHERE fecha = DATE '2022-03-23' ORDER BY tweets DESC LIMIT 5)
),
t3 AS (
  SELECT 3, FORMAT('[T3] tweets_gold.autores_alcance · todo el archivo · segmento de seguidores: %s',
         STRING_AGG(FORMAT('%s → %.2f %% de los tweets y %.2f %% de los likes', segmento, pct_tweets, pct_likes), '; ' ORDER BY segmento))
  FROM tweets_gold.autores_alcance
),
t4 AS (
  SELECT 4, FORMAT('[T4] tweets_gold.conversacion_dia · 2022-03-23 · tipo de tweet: %s',
         STRING_AGG(FORMAT('%s %d tweets, mediana %d likes', tipo, tweets, mediana_likes), '; ' ORDER BY tweets DESC))
  FROM tweets_gold.conversacion_dia
  WHERE fecha = DATE '2022-03-23'
),
t5 AS (
  SELECT 5, FORMAT('[T5] tweets_gold.aplicaciones_dia · 2022-03-23 · tres aplicaciones con más tweets: %s',
         STRING_AGG(FORMAT('%s %d', aplicacion, tweets), '; ' ORDER BY tweets DESC))
  FROM (SELECT aplicacion, tweets FROM tweets_gold.aplicaciones_dia
        WHERE fecha = DATE '2022-03-23' AND aplicacion != 'otras' ORDER BY tweets DESC LIMIT 3)
),
t6 AS (
  SELECT 6, FORMAT('[T6] tweets_gold.actividad_hora · 2022-03-23 · tres horas UTC con más tweets: %s',
         STRING_AGG(FORMAT('%d:00 → %d', hora_utc, tweets), '; ' ORDER BY tweets DESC))
  FROM (SELECT hora_utc, SUM(tweets) AS tweets FROM tweets_gold.actividad_hora
        WHERE fecha = DATE '2022-03-23' GROUP BY hora_utc ORDER BY tweets DESC LIMIT 3)
)
SELECT STRING_AGG(linea, '\n' ORDER BY o) AS contexto
FROM (SELECT * FROM t1 UNION ALL SELECT * FROM t2 UNION ALL SELECT * FROM t3
      UNION ALL SELECT * FROM t4 UNION ALL SELECT * FROM t5 UNION ALL SELECT * FROM t6);

Error frecuente y recuperación: Si una línea sale vacía o falta, esa tabla Gold no existe todavía en tu proyecto: créala con los scripts de la sesión 5. Si cambiaste la fecha, cambia las seis partes con DATE '2022-03-23'.

Paso 3 · Escribir el prompt con reglas · 10 min

Dónde: Un editor de texto. Más tarde lo pegarás en Vertex AI Studio.

Acción: Copia la plantilla y escribe dos versiones: A con el contexto del paso 1 y la pregunta «¿Qué anunció Putin sobre el pago del gas?»; B con el contexto del paso 2 y la pregunta «¿Qué tema tuvo más presencia el 23 de marzo en inglés?». No uses los dos contextos a la vez.

# Plantilla de prompt · cinco partes

Copia el bloque, sustituye lo que está entre llaves y pégalo en Vertex AI Studio.

```
ROL
Eres analista de inteligencia de mercado. Redactas para un comité que decide qué temas vigilar.

REGLAS
- Usa SOLO el contexto de abajo.
- Cada afirmación termina con la etiqueta de su fuente entre corchetes: [1], [2]… o [T1], [T2]…
- Si el contexto no alcanza para responder, escribe exactamente: «No hay evidencia en el contexto.»
- No afirmes causas. No inventes cifras ni etiquetas.

CONTEXTO
{pega aquí el resultado del paso 1 (cinco tweets) o del paso 2 (seis líneas de tablas Gold)}

PREGUNTA
{una sola pregunta concreta}

FORMATO
Máximo 120 palabras, en español, una frase por afirmación.
```

## Variantes que usarás en el laboratorio
- Versión A: CONTEXTO = salida del paso 1 · PREGUNTA = ¿Qué anunció Putin sobre el pago del gas?
- Versión B: CONTEXTO = salida del paso 2 · PREGUNTA = ¿Qué tema tuvo más presencia el 23 de marzo en inglés?

Salida esperada:

No hay salida de consulta: el resultado es un prompt de cinco partes (rol, reglas, contexto, pregunta, formato).

Comprueba: Las cinco partes están. La parte «reglas» contiene «solo el contexto», «cita la etiqueta» y la frase exacta «No hay evidencia en el contexto.»

Error frecuente y recuperación: Si pegas más contexto del necesario, el modelo lee más tokens y la respuesta cuesta más. Si olvidas la regla de las etiquetas, no podrás auditar en el paso 5.

# Pruebas para Vertex AI Studio

El texto del modelo cambia en cada ejecución. No compares palabras: comprueba que se cumplan las reglas.

## Prueba A · contexto = los cinco tweets del paso 1
- **P1 (se puede responder):** ¿Qué anunció Putin sobre el pago del gas?
  Debe citar [3] y/o [4].
- **P2 (no se puede responder):** ¿Cuántos tweets hablaron de energía ese día?
  Debe escribir «No hay evidencia en el contexto.» El contexto solo tiene cinco tweets.

## Prueba B · contexto = las seis líneas del paso 2
- **P3:** ¿Qué tema tuvo más presencia el 23 de marzo en inglés? Debe citar [T1]: energía, 10530 tweets (3.382 %).
- **P4:** ¿Quién concentra la interacción? Debe citar [T3] y hablar de porcentajes de tweets y de likes por segmento.
- **P5:** ¿Por qué subió la energía? Debe escribir «No hay evidencia en el contexto.» Ninguna tabla trae causas.

## Cómo juzgar cada respuesta
1. ¿Cada afirmación termina con una etiqueta que existe en tu contexto?
2. ¿Cada cifra aparece, tal cual, en esa etiqueta?
3. ¿Dice «No hay evidencia en el contexto.» donde debe?
Si alguna respuesta falla, anótalo: esa afirmación pasa a la auditoría del paso 5 como «inventada».

Salida esperada:

No hay una respuesta de referencia: el modelo redacta distinto en cada ejecución.
Lo que sí debe cumplirse:
- P1 cita [3] y/o [4].
- P2 escribe «No hay evidencia en el contexto.»
- P3 cita [T1] con energía 10530 (3.382 %).
- P4 cita [T3] con porcentajes por segmento.
- P5 escribe «No hay evidencia en el contexto.»

Comprueba: Cada afirmación termina con una etiqueta que existe en tu contexto, y P2 y P5 se declaran sin evidencia. Si no ocurre, anota cuál falló: pasará a auditoría.

Error frecuente y recuperación: Si el modelo da cifras sin etiqueta, endurece las reglas («Si una cifra no está en el contexto, no la escribas») y repite. Si no encuentras Vertex AI Studio, revisa que la API esté habilitada en tu proyecto y que tu cuenta tenga permiso para usarla.

Paso 5 · Auditar afirmaciones con SQL · 15 min

Dónde: BigQuery Studio → Nueva consulta.

Acción: Toma tres afirmaciones del texto que generó el modelo y, además, las seis del script (A1 a A6). Ejecuta el bloque de cada una. Asigna un veredicto: sustentada, contradicha o sin respaldo. A5 y A6 no se pueden decidir con las tablas.

Costo estimado: A1 726 B · A2 6,984 B · A3 195 B · A4 612 B · último bloque ≈ 19 MB (lee la tabla de autores).

-- Paso 5 · Auditar. Cada afirmación del texto generado se comprueba con una consulta sobre Gold.
-- Veredictos posibles: sustentada, contradicha, sin respaldo (el dato no puede decidirlo).

-- A1 «La energía fue el tema con más presencia el 23 de marzo en inglés.»  → sustentada
SELECT tema, tweets_tema, pct_del_dia
FROM tweets_gold.tema_dia
WHERE fecha = DATE '2022-03-23' AND grupo_idioma = 'en'
ORDER BY pct_del_dia DESC;

-- A2 «Las sanciones pesaron más en español que en inglés.»  → contradicha
SELECT grupo_idioma, SUM(tweets_tema) AS tweets, SUM(tweets_dia) AS base,
       ROUND(100 * SUM(tweets_tema) / SUM(tweets_dia), 2) AS pct
FROM tweets_gold.tema_dia
WHERE tema = 'sanciones'
GROUP BY grupo_idioma
ORDER BY pct DESC;

-- A3 «La mayoría de los likes viene de cuentas con más de un millón de seguidores.»  → contradicha
SELECT segmento, pct_tweets, pct_likes
FROM tweets_gold.autores_alcance
ORDER BY segmento;

-- A4 «La mitad de los tweets son respuestas.»  → sustentada
SELECT tipo, SUM(tweets) AS tweets,
       ROUND(100 * SUM(tweets) / SUM(SUM(tweets)) OVER (), 1) AS pct
FROM tweets_gold.conversacion_dia
GROUP BY tipo
ORDER BY tweets DESC;

-- A5 «Las sanciones causaron el pico de energía del 23 de marzo.»  → sin respaldo
-- A6 «A la gente en Europa le preocupó más la energía.»  → sin respaldo
-- Ninguna tabla Gold trae causas ni país: el idioma no es el país y cuatro de cada diez autores no declara ubicación.
-- Lo que sí puedes comprobar sobre A6 es cuántos autores dejaron la ubicación vacía:
SELECT COUNTIF(ubicacion IS NULL) AS autores_sin_ubicacion, COUNT(*) AS autores,
       ROUND(100 * COUNTIF(ubicacion IS NULL) / COUNT(*), 1) AS pct
FROM tweets_silver.autores;
