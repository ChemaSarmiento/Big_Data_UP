# El volumen del proyecto debe ser real y pertinente

`bank_transactions.csv` (~7.5 GB) sirve para práctica, pero no cumple por sí solo ≥15 GB.

- Elegir una fuente real suficiente o combinar fuentes pertinentes a la misma pregunta.
- No contar copias de las mismas filas ni resultados intermedios como datos nuevos.
- Registrar origen, tamaño, fecha, licencia y limitaciones.
- Depurar con muestras; demostrar ejecución sobre el volumen exigido.

**Defensa:** ¿qué decisión mejora al usar esas fuentes juntas?
