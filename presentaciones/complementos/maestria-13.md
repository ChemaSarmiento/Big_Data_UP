# Gobernar también es asignar un responsable

| Control | Pregunta que debe responder el equipo |
|---|---|
| Acceso | ¿Quién puede leer, modificar y compartir cada dato? |
| Calidad | ¿Qué validación detiene un lote incorrecto? |
| Linaje | ¿Qué versión del dato y del modelo produjo este resultado? |
| Operación | ¿Quién atiende una falla y cómo recupera el servicio? |

**Evidencia del capstone:** muestra el recorrido de una predicción desde su entrada hasta el resultado, con versiones y validaciones identificables.

# El capstone demuestra escala, procedencia y reproducibilidad

- El dataset bancario de práctica (~7.5 GB) no cubre solo el mínimo ≥15 GB.
- La fuente grande necesita una tarea/modelo coherente; si no hay etiqueta, definir otro objetivo explícito.
- Asociar código, corte temporal, datos, modelo, métricas y costo a una versión.
- Mostrar una falla recuperada o un candidato rechazado, además del camino exitoso.

**Evidencia:** manifiesto de datos y ejecución sobre volumen real; no filas replicadas para inflar el tamaño.
