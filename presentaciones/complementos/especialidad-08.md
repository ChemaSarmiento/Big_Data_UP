# La recomendación necesita condiciones verificables

No basta con recomendar «sí» o «no». Cada riesgo debe convertirse en una condición con responsable y evidencia.

| Hallazgo | Condición para aprobar |
|---|---|
| No hay presupuesto de referencia | Estimar el costo mensual y el escenario de crecimiento |
| Nadie administra permisos | Asignar un responsable y revisar los accesos |
| No hay prueba de recuperación | Demostrar cómo se recupera una ejecución fallida |
| No se identifica al consumidor | Definir quién usa el resultado y qué decisión cambia |

**Salida del taller:** decisión + condiciones + evidencia necesaria para revisarla.
